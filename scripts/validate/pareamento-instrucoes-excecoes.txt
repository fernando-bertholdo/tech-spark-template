# Exceções de pareamento entre .claude/skills/ e .agents/skills/
#
# Lido por scripts/validate/check-pareamento-instrucoes.sh, que é cópia do gate do
# tech-product-template e documenta o formato no próprio cabeçalho. Resumo:
#
#   tipo           | caminho                   | motivo ou literal
#
#   solo           — arquivo que existe numa família e legitimamente não na outra.
#                    Caminho COM o prefixo da família.
#   divergencia    — homônimo que diverge por design. Caminho relativo à família.
#                    Sozinha não isenta nada: só isenta o que as linhas `trecho` e
#                    `secao` do mesmo caminho declaram, e o resto do par é comparado
#                    byte a byte.
#   trecho <fam.>  — literal que sai do lado daquela família antes da comparação.
#   secao          — seção de título ATX que sai dos dois lados; `*` isenta o arquivo
#                    inteiro e só vale declarado sozinho.
#   drift          — homônimo que diverge por acidente e vai ser reconciliado.
#
# Linhas `trecho` e `secao` não têm comentário: o literal vem cru. Exceção obsoleta
# falha o gate igual a drift não declarado: remova a linha no mesmo commit que
# reconcilia o par ou apaga o arquivo. Motivo genérico ("exclusivo", "difere") não
# vale — o motivo é o que torna a exceção auditável.
#
# O cabeçalho do gate é o da origem, byte a byte: o harness, os cenários P33 e
# P35, a `.codex/` e as medições que ele cita existem no tech-product-template, não
# aqui. Mudar o script é mudar a cópia da origem; o que vale para este repositório
# está neste arquivo.
#
# Alcance: só skills/. Desde 31/10/2026 (TECH-1308) as rules vivem só em
# .claude/rules/, como no tech-product-template desde a TECH-852, e os pontos de
# entrada (.claude/CLAUDE.md e .agents/README.md) ficam fora do gate.
